# Contract — Documentation site structure (English)

The site is published at `https://ck-developer.github.io/inkpdf/`. Pages marked (gen) are
generated by `cargo xtask docs generate` and checked in CI.

```text
Introduction                          what inkpdf is (a foundation), what it is not
Getting started
  Run with Docker                     first PDF in minutes
  Your first template                 smallest template: main.typ + schema.json
Concepts
  Templates                           a folder; manifest, schema, Typst sources, assets, fonts
  The request body                    data / layout / metadata — data and layout are defined by
                                      each template's own schema; metadata is service-defined
  Schemas and defaults                JSON Schema rules, layout defaults, validation errors
  Bundled packages                    import by name, installed version, isolation
  Hot reload                          volume, fingerprints, invalid templates
  Sandbox and determinism             no network, no files outside, identical bytes
Guides
  Writing a template                  step by step
  Best practices                      schema design, layout parameters, exact amounts, dates,
                                      file splitting, multi-page tables, testing
  Using bundled packages              QR codes, charts, amounts, dates
  Downloads and PDF metadata
  Exploring the API                   live /docs and /openapi.json per template; Bruno collection
  Walkthrough: a progress invoice     the example as an illustration of the practices above
Reference
  HTTP API (gen)                      generic routes from openapi.json + pointer to the live doc
  Error codes (gen)
  Configuration                       INKPDF_* variables
  Template format                     files, manifest fields, schema root rules, imports
  Bundled packages (gen)
Operations
  Deployment                          image tags, volume, health checks, compose/Kubernetes notes
  Limits and performance              body size, timeouts, concurrency, WASM caveat
  Security                            private network, no auth, sandbox, reporting
Contributing
  Architecture                        crates, request flow, registry, World
  Development and tests
  Adding or updating a package        cargo xtask packages
  Releasing                           conventional commits, release PRs, images
```
